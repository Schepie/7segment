Battery & Pro Tips

  • Serve Indicator: The serving team's next unearned game LED gently pulses in Gold on the central ladder. In tiebreaks, 1 or 2 solid gold dots show 1st/2nd serve.
  • First Server Toss: Double-click either remote button before the first point (at 0–0) to choose which team serves first.
  • Coin Battery: Uses a standard CR1632 3V cell (lasts ~6–12 months). Twist open rear cap using a coin to replace.
  • Deep Sleep: Remote enters sleep when unused. One click wakes it back up and re-links automatically.
  • Undo Window: Double-click has a 380ms threshold. Keep deliberate pace when scoring consecutive points.
